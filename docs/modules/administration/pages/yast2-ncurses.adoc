[#cha-yast-text]
= {yast} in text mode
:description: Navigate and manage systems without an X server using the ncurses-based YaST interface over SSH or a local terminal
:revdate: 2026-01-16

The ncurses-based pseudo-graphical {yast} interface is designed primarily to help system administrators to manage systems without an X server. The interface offers several advantages compared to the conventional GUI. You can navigate the ncurses interface using the keyboard, and there are keyboard shortcuts for practically all interface elements. The ncurses interface is light on resources, and runs fast even on modest hardware. You can run the ncurses-based version of {yast} via an SSH connection, so you can administer remote systems. Keep in mind that the minimum supported size of the terminal emulator in which to run {yast} is 80x25 characters.

[#fig-yast2-ncurses]
.Main window of {yast} in text mode
image::yast2_ncurses_main.png["",width=75%]

To launch the ncurses-based version of YaST, open the terminal and run the `+sudo yast2+` command. Use the kbd:[Tab] or arrow keys to navigate between interface elements like menu items, fields and buttons. All menu items and buttons in {yast} can be accessed using the appropriate function keys or keyboard shortcuts. For example, you can cancel the current operation by pressing kbd:[F9], while the kbd:[F10] key can be used to accept the changes. Each menu item and button in {yast}'s ncurses-based interface has a highlighted letter in its label. This letter is part of the keyboard shortcut assigned to the interface element. For example, the letter `+Q+` is highlighted in the *Quit* button. This means that you can activate the button by pressing kbd:[Alt,Alt{plus}Q].

[TIP]
.Refreshing {yast} dialogs
====
If a {yast} dialog gets corrupted or distorted, for example, while resizing the window, press kbd:[Ctrl+L] to refresh and restore its contents.
====

[#sec-yast-cli-navigate]
== Navigation in modules

The following description of the control elements in the {yast} modules assumes that all function keys and kbd:[Alt] key combinations work and are not assigned to different global functions. Read <<sec-yast-cli-restricted-keys,Restriction of key combinations>> for information about possible exceptions.

Moving between buttons and selection lists::
Use kbd:[Tab] to move between the buttons and frames containing selection lists. To navigate in the opposite direction, use kbd:[Alt+Tab] or kbd:[Shift+Tab] combinations.
Navigating in selection lists::
Use the arrow keys (kbd:[up] and kbd:[down]) to move through the individual elements in an active frame containing a selection list. If individual entries are longer than the frame's width, use kbd:[Shift+right] or kbd:[Shift+left] to scroll horizontally. If the arrow key causes the selection to move to another frame, use kbd:[Ctrl+E] or kbd:[Ctrl+A] instead.
Working with buttons, radio buttons, and check boxes::
To select items with empty square brackets (check boxes) or empty parentheses (radio buttons), press kbd:[Space] or kbd:[Enter]. Alternatively, radio buttons and check boxes can be selected directly with kbd:[Alt+highlighted_letter]. In this case, you do not need to confirm with kbd:[Enter]. If you navigate to an item with kbd:[Tab], press kbd:[Enter] to execute the selected action or activate the respective menu item.
Function keys::
The function keys (from kbd:[F1] to kbd:[F12]) enable quick access to the specific buttons. Available function key combinations (`F__X__`) are shown in the bottom line of the {yast} screen. Which function keys are really mapped to which buttons depend on the active {yast} module, because the different modules offer different buttons (*Details*, *Info*, *Add*, *Delete*, etc.). Use kbd:[F10] for *Accept*, *OK*, *Next*, and *Finish*. Press kbd:[F1] to access the {yast} help.
Using the navigation tree::
Certain {yast} modules use a navigation tree in the left part of the window to select configuration dialogs. Use the arrow keys (kbd:[up] and kbd:[down]) to navigate in the tree. Use kbd:[Space] to open or close tree items. In the ncurses mode, kbd:[Enter] must be pressed after a selection in the navigation tree to show the selected dialog. This is an intentional behavior to save time-consuming redraws when browsing through the navigation tree.
Selecting software in the software installation module::
Use the filters on the left side to list packages matching the specified string. Installed packages are marked with the letter `+i+`. To change the status of a package, press kbd:[Space] or kbd:[Enter]. Alternatively, use the *Actions* menu to select the needed status change (install, delete, update, taboo or lock).

[#sec-yast-cli-restricted-keys]
== Restriction of key combinations

If your window manager uses global kbd:[Alt] combinations, the kbd:[Alt] combinations in {yast} may not work. Keys like kbd:[Alt] or kbd:[Shift] can also be occupied by the settings of the terminal.

Using kbd:[Alt] instead of kbd:[Esc]::
kbd:[Alt] shortcuts can be executed with kbd:[Esc] instead of kbd:[Alt]. For example, kbd:[Esc+H] replaces kbd:[Alt+H]. (Press kbd:[Esc], _then_ press kbd:[H].)
Backward and forward navigation with kbd:[Ctrl+F] and kbd:[Ctrl+B]::
If the kbd:[Alt] and kbd:[Shift] combinations are taken over by the window manager or the terminal, use the combinations kbd:[Ctrl+F] (forward) and kbd:[Ctrl+B] (backward) instead.
Restriction of function keys::
The function keys (kbd:[F1] \... kbd:[F12]) are also used for functions. Certain function keys may be taken over by the terminal and may not be available for {yast}. However, the kbd:[Alt] key combinations and function keys should always be fully available on a text-only console.

[#sec-yast-cli-options]
== {yast} command line options

Besides the text mode interface, {yast} provides a command line interface. To get a list of {yast} command line options, use the following command:

----
> sudo yast -h
----

[#sec-yast-cli-options-install]
=== Installing packages from the command line

If you know the package name, and the package is provided by an active installation repository, you can use the command line option `+-i+` to install the package:

[subs="specialchars,quotes,attributes,callouts"]
----
> sudo yast __-i package{underscore}name__
----

or

[subs="specialchars,quotes,attributes,callouts"]
----
> sudo yast --install __-i package{underscore}name__
----

_package_name_ can be a single short package name, for example, `+gvim+`, installed with dependency checking, or the full path to an RPM package, which is installed without dependency checking.

While {yast} offers basic functionality for managing software from the command line, consider using Zypper for more advanced package management tasks. Find more information on using Zypper in xref:sw-managing-commandline.adoc#sec-zypper[Using Zypper].

[#sec-yast-cli-options-modules]
=== Working with individual modules

To save time, you can start individual {yast} modules using the following command:

[subs="specialchars,quotes,attributes,callouts"]
----
> sudo yast __module{underscore}name__
----

View a list of all modules available on your system with `+yast -l+` or `+yast --list+`.

[#sec-yast-cli-options-module-params]
=== Command line parameters of {yast} modules

To use {yast} functionality in scripts, {yast} provides command line support for individual modules. However, not all modules have command line support. To display the available options of a module, use the following command:

[subs="specialchars,quotes,attributes,callouts"]
----
> sudo yast __module{underscore}name__ help
----

If a module does not provide command line support, it is started in a text mode with the following message:

[subs="attributes+"]
----
This {yast} module does not support the command line interface.
----

The following sections describe all {yast} modules with command line support, along with a brief explanation of all their commands and available options.

==== Common {yast} module commands

All {yast} modules support the following commands:

help::
Lists all the module's supported commands with their description:
+
----
> sudo yast lan help
----
longhelp::
Same as `+help+`, but adds a detailed list of all command's options and their descriptions:
+
----
> sudo yast lan longhelp
----
xmlhelp::
Same as `+longhelp+`, but the output is structured as an XML document and redirected to a file:
+
----
> sudo yast lan xmlhelp xmlfile=/tmp/yast_lan.xml
----
interactive::
Enters the _interactive_ mode. This lets you run the module's commands without prefixing them with `+sudo yast+`. Use `+exit+` to leave the interactive mode.

==== yast add-on

Adds a new add-on product from the specified path:

----
 > sudo yast add-on http://server.name/directory/Lang-AddOn-CD1/
----

You can use the following protocols to specify the source path: http:// ftp:// nfs:// disk:// cd:// or dvd://.
