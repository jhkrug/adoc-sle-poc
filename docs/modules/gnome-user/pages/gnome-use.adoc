[#sec-gnomeuser-use-nautilus]
== Managing files and directories

To start {nautilus}, open the *Activities* overview by pressing kbd:[Meta] and search for `+files+`. Then select *Files* from the hit list.

.File manager
image::nautilus.png["The elements and contents of the GNOME file manager",width=75%]

The elements of the {nautilus} window include the following:

Toolbar::
The toolbar on top contains back and forward buttons, the path bar with the search function, view options (list or grid view), icon sorting options and the three-dot menu containing actions and settings for the currently displayed folder.
Sidebar::
The sidebar lets you navigate between often used directories and external or network storage devices, displays connected devices and volumes enables drag-and-drop operations to or from listed locations. To display or hide the sidebar, press kbd:[F9].
Main menu::
The three-line menu icon at the top of the sidebar lets you perform many tasks, such as opening the preferences dialog, changing icon sizes, creating a new directory or opening a new window or tab.
Content area::
This area displays the files and directories. Use the three-dot menu in the top right to switch between list and grid icon view.
Context menus::
Open a context menu by right-clicking inside the content area. The items in this menu depend on where you right-click.
+
For example, if you right-click a file or directory, you can select items related to the file or directory. If you right-click the background of a content area, you can select items related to the display of items in the content area.

[#sec-gnomeuser-use-nautilus-archiving]
=== Compressing files or directories

Sometimes, it is useful to archive or compress files, for example:

* You want to attach an entire directory, including its subdirectories, to an e-mail.
* You want to attach a large file to an e-mail.
* You want to save space on your hard disk and have files you rarely use.

In all these cases, you can create a compressed file, such as a `+ZIP+` file, which can contain multiple original files. How much smaller a file becomes after compression varies depending on the file type. Many video, image and office document formats are already compressed and will only become marginally smaller.

. In the {nautilus} content area, right-click the directory you want to archive, then click *Compress*.
. Enter an archive file name.
. Select a file extension from the drop-down list.
+
* `+.zip+` files are compatible with all operating systems.
* `+.tar.xz+` files are compatible only with Linux{asterisk} and Mac{asterisk} systems.
* `+.7z+` are smaller archives but must be installed on Windows{asterisk} and Mac{asterisk}.
. Specify a location for the archive file, then click *Create*.

To extract an archived file, right-click the file, then select *Extract Here*. You can also double-click the compressed file to open it and see which files are included.

For more information on compressed files, see <<sec-gnomeuser-use-archives,Creating, displaying and decompressing archives>>.

[#sec-gnomeuser-use-nautilus-burn]
=== Burning a CD/DVD

If your system has a CD or DVD writer, you can use {nautilus} to burn CDs and DVDs.

. Open {nautilus}.
. Insert a blank medium.
. Find the files you want to add to the medium and drag them to the sidebar item called *Blank CD-R Disc*. (The label may read slightly differently, depending on the type of medium you inserted.) When your mouse pointer is over the sidebar item, a small `{plus}` should appear next to the pointer.
. When you have dragged all files onto the sidebar item *Blank CD-R Disc*, click it.
. Provide a name next to *Disc Name* or keep the proposal.
. Click *Write to Disc*.
. In the appearing dialog *CD/DVD Creator*, make sure the right medium is selected. Then click *Burn*.
+
The files are burned to the disc. This can take a few minutes, depending on the amount of data being burned and the speed of your burner.
. After the medium has been burned, it is ejected from the drive. In the window *CD/DVD Creator*, you can click *Close*.

To burn an ISO disc image, first insert a medium, then double-click the ISO file in {nautilus}. In the dialog *Image Burning Setup*, click *Burn*.

[#sec-gnomeuser-use-nautilus-bookmarks]
=== Creating a bookmark

Use the bookmarks feature in {nautilus} to quickly jump to your favorite directories from the sidebar.

. In the content area of the file manager, open the folder or location you want to bookmark.
. Click the current folder in the path bar and select *Add to Bookmarks*.
+
The bookmark now appears in the sidebar, with the directory name as the bookmark name.
. You can change the name of the bookmark. This does not affect the name of the bookmarked directory itself. To change the name, right-click the new sidebar item and select *Rename*.
. You can change the order in which the bookmarks are displayed. To reorder, click a bookmark and drag it to another location.

To switch to a bookmarked directory, click the appropriate sidebar item.

[#sec-gnomeuser-use-media]
== Accessing removable media

To access devices like USB flash drives or CDs/DVDs, insert or attach the medium. An icon for the medium is automatically created on the desktop. For many types of removable media, a {nautilus} window pops up automatically. If {nautilus} does not open, double-click the icon for that drive on the desktop to view the contents. In {nautilus}, an item for the medium in the sidebar appears.

[WARNING]
.Unmount to prevent data loss
====
Do not physically remove devices immediately after using them. Even when the system does not indicate that data is being written, the drive may not be finished with a previous operation.
====

To safely remove a device, proceed as follows:

. From the *Activities* overview, open *Files*.
. Locate the device in the sidebar and click the *Eject* icon.
+
Now you can safely remove the device.

[#sec-gnomeuser-use-search-files]
== Searching for files

There are multiple ways to search for files or directories. In all cases, the search is performed on file and directory names. Searching by file size, modification date and other properties is only partially possible in the preinstalled graphical tools. Such searches are easier to do on the command line.

Using {nautilus}::
In {nautilus}, navigate to the directory from which you want to start the search. Then start typing the search term. To search for objects with a certain modification date or file type, click the arrow-down icon of the search box and modify the properties.
Using the *Activities* overview::
Open the *Activities* overview by pressing kbd:[Meta] on your keyboard. Then start typing the search term. The search is performed within your home directory.

[#sec-gnomeuser-use-cutnpaste]
== Copying text between applications

Copy and paste works the same as in any other operating system. First select the text, so that it appears highlighted. Then press kbd:[Ctrl+C]. Now move the keyboard focus to the right position. Finally, to insert the text, press kbd:[Ctrl+V].

To copy or paste in the terminal, additionally press kbd:[Shift] together with the above key combinations.

An alternative way of using copy and paste is described in the following:

. Select the text to be copied.
. Go to the location where the text should be inserted, right-click the mouse button and select *Paste* from the context menu.
+
As soon as you make another selection, the text from the original selection is replaced in the clipboard.

When copying information between programs, you must keep the source program open and paste the text before closing it. When a program closes, any content from that application that is on the clipboard is lost.

== Managing Internet connections

To surf the Web or send and receive e-mail messages, you must have configured an Internet connection. If you have installed {productname} on a laptop or a mobile device, {nm} is enabled by default. On the {gnome} desktop, you can then establish Internet connections with {nm} as described in xref:administration:nm.adoc#sec-nm-configure[Configuring network connections].

Depending on your environment, you can choose in {yast} which basic service to use for setting up network connections (either {nm} or wicked). For details, see xref:administration:net-basic.adoc#sec-network-yast-netcard-global[Configuring global networking options].

[#sec-gnomeuser-use-mail]
== E-mail and scheduling

The {gnome} desktop offers Evolution, a personal information management application that provides integrated mail, calendaring and address book functionality.

Evolution seamlessly combines e-mail, a calendar, an address book, and a memo and task list in one easy-to-use application. With its extensive support for communications and data interchange standards, it can work with existing corporate networks and applications, including Microsoft{asterisk} Exchange.

image::evolution.png["Evolution start view showing the inbox and navigation panel for e-mail, calendar, contacts and tasks",width=80%]

To start Evolution, open the *Activities* overview by pressing kbd:[Meta] and type `+mail+`.

The first time you start Evolution, it prompts you with a few questions to set up a mail account and import mail from an old mail client. Then it shows you how many new messages you have and lists upcoming appointments and tasks. The calendar, address book and mail tools are available in the shortcut bar on the left.

For more information, see xref:apps-evolution.adoc[].

[#sec-gnomeuser-use-archives]
== Creating, displaying and decompressing archives

You can use the Archive Manager application to create, view, modify or unpack an archive. An archive is a file that acts as a container for other files. An archive can contain many files, directories and subdirectories, mostly in compressed form. You can use Archive Manager to create, open and extract a compressed non-archive file.

Archive Manager supports common formats, such as:

* `+zip+`
* `+tar+`
* `+lzh+`
* `+rar+`

To start *Archive Manager*, open the *Activities* overview by pressing kbd:[Meta] and type `+arch+`.

If you already have a compressed file, double-click the file name in {nautilus} to view the contents of the archive in Archive Manager.

.Archive manager
image::file_roller.png["Archive Manager view showing options to create, open and extract compressed archives",width=70%]

[#sec-gnomeuser-use-archives-open]
=== Opening an archive

. Open Archive Manager, click the menu button in the upper right corner of the window, and select *Open*.
. Select the archive you want to open and click *Open*.
+
Archive Manager displays the following:
+
* The archive name in the path bar.
* The archive contents in the content area.
+
To open another archive, click *Open* again. Archive Manager opens each archive in a new window.
. To display the archive's properties, click the menu button in the path bar and select *Properties*. Details like name, location, type, last modification, number of files, size, and compression ratio are shown.

[#sec-gnomeuser-use-archives-extract]
=== Extracting files from an archive

. Open Archive Manager and select the files you want to extract.
. Click *Extract*.
. Specify the directory where to extract the files.
. Choose from the following extraction options:
+
[cols="35,65",options="header"]
|===
a|Option
a|Description

a|All files
a|Extracts all files from the archive.
a|Selected files
a|Extracts the selected files from the archive.
a|Files
a|Extracts from the archive all files that match the specified pattern.
a|Keep directory structure
a|Reconstructs the directory structure when extracting the specified files.

For example, you specify `+/tmp+` in the *Filename* text box and extract all files. The archive contains a subdirectory called `+doc+`. If you select the *Keep directory structure* option, Archive Manager extracts the contents of the subdirectory to `+/tmp/doc+`.

If you do not select the *Keep directory structure* option, Archive Manager does not create any subdirectories. Instead, it extracts all files from the archive, including files from subdirectories, to `+/tmp+`.
a|Do not overwrite newer files
a|If not active, Archive Manager overwrites any files in the destination directory that have the same name as the specified files.

If you select this option, Archive Manager does not extract the specified file if an existing file with the same name already exists in the destination directory.
|===
. Click *Extract*.
+
To extract an archived file in a file manager window without opening Archive Manager, right-click the file and select *Extract Here*.
+
The operation extracts a copy of the specified files from the archive. The extracted files have the same permissions and modification date as the original files that were added to the archive.
+
The Extract operation does not change the contents of the archive.

[#sec-gnomeuser-use-archives-create]
=== Creating archives

. In Archive Manager, click the menu button in the upper right part of the window and select *New Archive*.
. Specify the name and location of the new archive.
. Select an archive type from the drop-down box.
. Click *Create*.
+
Archive Manager creates an empty archive, but does not yet write the archive to disk. A new archive is only written to the disk when the archive contains at least one file. If you create a new archive and quit Archive Manager before adding any files, the archive is deleted.
. Add files and directories to the new archive:
+
.. Click *Add Files* and select the files or directories you want to add.
.. Click *Add*.
+
Archive Manager adds the files to the current directory in the archive.

You can also add files to an archive in a file manager window without opening Archive Manager. See <<sec-gnomeuser-use-nautilus-archiving,Compressing files or directories>> for more information.

[#sec-gnomeuser-use-screnshots]
== Taking screenshots

You can take a snapshot of your screen or of an individual application window by using the *Screenshot* application. The screenshots are automatically saved to your `+~/Pictures+` folder in your home directory.

Use the following global key combinations to quickly take a screenshot:

* kbd:[Print] takes a screenshot of the entire desktop.
* kbd:[Alt+Print] takes a screenshot of a window.
* kbd:[Shift+Print] takes a screenshot of an area you select.

You can also use GIMP to take screenshots as described in the following:

. Open GIMP and select menu:File[Create > Screenshot].
. Select an area, choose a delay and then click *Snap*.

For more information on GIMP, see xref:apps-gimp.adoc[].

[#sec-gnomeuser-use-pdfs]
== Viewing PDF files

The Evince Document Viewer can open PDF files and many similar file types, such as `+XPS+`, `+DjVu+`, or `+TIFF+`.

[NOTE]
.Rare display issues
====
In rare cases, documents may not be displayed correctly in Document Viewer. This can happen, for example, with certain forms, animations or 3D images. In such cases, ask the authors of the file what viewer they recommend. However, in rare cases, the recommended viewer may not work on Linux.
====

.Document viewer
image::evince.png["Document Viewer main view showing an open PDF document with navigation sidebar, toolbar controls and reading pane",width=78%]

To open Document Viewer, double-click a PDF file in a file manager window. Document Viewer also opens when you download a PDF file from a Web site.

To open Document Viewer without a file, open the *Activities* overview by pressing kbd:[Meta] and typing `+pdf+`.

To view a PDF file in Document Viewer, click *Open*, navigate to the PDF file and click *Open* again.

Use the side pane to navigate through the document. If your PDF document provides bookmarks, you can access them in the side pane as well.
