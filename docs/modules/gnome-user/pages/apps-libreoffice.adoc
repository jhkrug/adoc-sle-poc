= {libo}: the office suite
:description: Explore LibreOffice, the open source office suite for writing, spreadsheets, presentations, graphics, templates, and cross-platform file sharing
:revdate: 2026-01-16

[abstract]
--
{libo} is an open source office suite that provides tools for all types of office tasks, such as writing texts, working with spreadsheets, or creating graphics and presentations. With {libo}, you can use the same data across different computing platforms. You can also open and edit files in other formats, including Microsoft{asterisk} Office{asterisk} formats, then save them back to this format, if needed. This chapter contains information that applies to all {libo} modules.

Please note that not all of the {libo} modules are installed by default.
--

[#sec-lo-oview-start]
== Starting {libo}

There are multiple methods to directly start one of the {libo} modules:

* Click the *Activities* overview and type `+libre+` in the search box. Click the {libo} module you want to open.
* If any {libo} module is open, you can start any of the other modules by clicking menu:File[New] in the {libo} module and then selecting the type of document you want to create.
* As an alternative, use the command `+libreoffice+` and one of the options `+--writer+`, `+--calc+`, `+--impress+`, `+--draw+`, or `+--base+` to start the respective module.
+
{libo} has many command-line options, especially for allowing document conversions. To learn more about the command-line options of {libo}, see `+libreoffice --help+` or the man page of {libo} (`+man libreoffice(1)+`).

Before you start working with {libo}, you may be interested in changing some options from the Preferences dialog. In any {libo} module, click menu:Tools[Options] to open the dialog. The most important settings are:

menu:{libo}[User Data]::
Specify your user data such as company, first and last name, street, city and other useful information. This data has many uses: It is used in the comment functions of {libo} Writer and Calc, for authorship information in PDF documents, and for serial letters in Writer.
menu:{libo}[Fonts]::
Map font names to installed fonts. This can be useful if you exchange documents with others and the document you received contains fonts that are not available on your system.
menu:Load/Save[General]::
Contains loading and saving specific options. For example, you can choose whether to always create a backup copy and which file format {libo} should use by default.

To learn more about configuring {libo}, see <<sec-lo-oview-global,Changing the global settings>>.

[#sec-lo-interface]
== The {libo} user interface

The user interface of most of {libo} is very similar across its modules:

Menu bar::
At the top of the application, there is the menu bar which gives access to almost all functionality of {libo}. The menu bar can be customized to include more or fewer functions. You can also add and remove menus.
Toolbars::
By default, the toolbars are positioned directly below the menu bar. The toolbars comprise the most used and most important items of the module.
+
To dock a toolbar to any other side of the window, drag it to the right position. To make a toolbar float, drag it into the middle of the window. They can be customized to include more or fewer functions. You can also add and remove toolbars.
Side bar::
By default, the side bar is positioned at the right side of the {libo} window. On the first start of {libo}, it is only visible as several icons stacked vertically. Clicking one of the icons opens a panel with more elements. Click the icon again to close the panel. Similarly to the toolbars, the side bar comprises the most important functions.
+
To dock the side bar to the left or right side of the window, drag it to the right position. To make the side bar float, drag it into the middle of the window. To hide the side bar, click the vertical arrowhead button on the document-facing side of the side bar.
+
You can hide or show side bar panels but cannot customize their functionality.
Statusbar::
The statusbar is displayed at the bottom of the window. It mainly shows information about the document, such as the number of words (in Writer) or the sum of values of selected cells (in Calc). However, it can also be used to change the zoom or language settings. Many elements open additional menus or dialogs on left-click, right-click, or double-click.

For more information on customizing {libo}, see <<sec-lo-oview-cust,Customizing {libo}>>.

[#sec-lo-oview-migration]
== Compatibility with other office applications

The native file format of {libo} is the OpenDocument format. OpenDocument is an ISO-standardized format for office documents that is based on XML. However, {libo} can also work with documents, spreadsheets, presentations, and databases in many other formats, including Microsoft Office formats. Files in Microsoft Office formats can be opened and saved back normally.

[#sec-lo-openother]
=== Opening documents from other office suites

If you use {libo} in an environment where you need to share documents with Microsoft Word users, you should have little or no trouble exchanging document files. However, very complex documents can require editing after opening. Complex documents are documents containing, for example, complicated tables, Microsoft Office macros, or unusual fonts, formatting, or graphical objects.

In case there should ever be issues with opening documents, try the following strategies:

* {empty}
+
.Text documents
Consider opening text documents in the original application and saving them as RTF or plain text (TXT). However, saving as plain text means that all formatting will be lost.
* {empty}
+
.Spreadsheets
Consider opening spreadsheets in the original application and saving them as Excel files. If this does not work, try the CSV format. However, saving as CSV means that all formatting, cell type definitions, formulas, and macros will be lost.

[#sec-lo-oview-migration-convert]
=== Converting documents to the OpenDocument format

{libo} can read, edit and save documents in several formats. It is not necessary to convert files from those formats to the OpenDocument format used by LibreOffice to use those files. However, if you want to convert the files, you can do so. To convert several documents, such as when first switching to {libo}, do the following:

. Select menu:File[Wizards > Document Converter].
. Choose the file format from which to convert.
. Click *Next*.
. Specify where {libo} should look for templates and documents to convert and in which directory the converted files should be placed.
+
Documents retrieved from a Windows partition are usually in a subdirectory of `+/windows+`.
. Make sure that all other settings are correct, then click *Next*.
. Review the summary of the actions to perform, then start the conversion by clicking *Convert*.
+
The amount of time needed for the conversion depends on the number of files and their complexity. For most documents, conversion does not take long.
. When everything is done, close the Wizard.

[#sec-lo-oview-migration-share]
=== Sharing files with users of other office suites

{libo} is available for several operating systems. This makes it an excellent tool when a group of users frequently need to share files and do not use the same system on their computers.

When sharing documents with others, you have several options:

If the recipient needs to be able to edit the file::
Save the document in the format the other user needs. For example, to save as a Microsoft Word file, click menu:File[Save As], then select the Microsoft Word file type for the version of Word the other user needs.
If the recipient only needs to read the document::
Export the document to a PDF file with menu:File[Export > Export as PDF]. PDF files can be read on any platform using a PDF viewer.
Sharing a document for editing::
Agree on a common exchange format that works for everyone. TXT and RTF formats, although limited in formatting, can be a good option for text documents.
E-mailing a document as a PDF::
Click menu:File[Send > E-mail as PDF]. Your default e-mail program opens with the file attached.
E-mailing a document to a Microsoft Word user::
Click menu:File[Send > E-mail as Microsoft Word]. Your default e-mail program opens with the file attached.

[#sec-lo-oview-passwd]
== Saving files with a password

You can save files, no matter in which {libo} format, with a password. Unlike older versions of {libo}, the encryption applied to the document with recent versions of {libo} is very strong. However, this encryption does not protect file names and file sizes of encrypted files. If that is important to you, see the alternate encryption methods described in xref:security:security-cryptofs.adoc[].

[#pro-lo-encrypt]
. To save a file with a password, select menu:File[Save] or menu:File[Save As].
. In the dialog that opens, activate the check box *Save with password* at the bottom and click *Save*.
. Type and confirm your password, then click *OK*.

The next time you open the file, you will be prompted for the password.

To change the password, do either of the following:

* Overwrite the same file by selecting menu:File[Save As]. Make sure *Save with Password* is deactivated.
* Select menu:File[Properties] and click *Change Password* in the *General* tab to access the password dialog.

[#sec-lo-oview-certstore]
== Signing documents

You can digitally sign documents to protect them. For this, you need a personal certificate, similar to an HTTPS certificate. You can either create a self-signed certificate or choose to obtain one from a Certificate Authority. For more information on how to obtain such a certificate, please see link:https://help.libreoffice.org/latest/en-US/text/shared/guide/digitalsign_send.html[].

When applying a digital signature to a document, a kind of checksum is created from the document's content and your personal key. The checksum is stored together with the document.

When another person opens the document, the checksum will be generated again. The new checksum is then compared to the original one. If both are equal, the application will signal that the document has not changed in the meantime.

To add a certificate to {libo}, you need to use Firefox:

[#pro-lo-importcertificate]
. To start Firefox, open the *Activities* overview by pressing kbd:[Meta] and search for `+fire+`.
. Go to the certificates preferences by clicking on the menu button, then select menu:Settings[Privacy & Security].
. Go to the section menu:Security[Certificates].
. Add your certificate by selecting *View Certificates* and clicking *Import* and then locate your certificate.

To sign a document, first open it in {libo}. Then select menu:File[Digital Signatures > Digital Signatures]. Select the certificate you want to use for signing, then click *Save*.

For more info, refer to link:https://help.libreoffice.org/latest/en-US/text/shared/guide/digital_signatures.html?DbPAR=SHARED[].

[#sec-lo-oview-cust]
== Customizing {libo}

You can customize {libo} to best suit your needs and working style. Toolbars, menus and key combinations can all be reconfigured to help you more quickly access the features you use the most.

You can also assign macros to application events if you want specific actions to occur when those events take place. For example, if you always work with a specific spreadsheet, you can create a macro that opens the spreadsheet and assign the macro to the *Start Application* event.

This section contains simple, generic instructions for customizing your environment. The changes you make are effective immediately. This means you can see if the changes are what you wanted and go back and modify them if they are not. See the {libo} help files for detailed instructions.

To access the customization dialog in any open {libo} module, select menu:Tools[Customize].

[#fig-lo-oview-custom]

image::oo_customize_main.png["LibreOffice Writer's menu customization interface, showing available commands like 3D Color and zoom options on the left, with assigned File menu commands on the right",width=80%]

[NOTE]
.More information
====
Click *Help* for more information about the options in the *Customize* dialog.
====

.Customizing menus
You can add or delete items from current menus, reorganize menus and even create new menus.

. Click menu:Tools[Customize > Menus].
. In the right column in the *Target* drop-down box, select the menu you want to customize.
. To add menu items, select an item from the *Available commands* list and add it by clicking the right arrow. To remove an item, select it and click the left arrow.
. To rearrange the order of items in the menu, select an item and drag it to another position.
. To switch back to the original settings, click *Defaults* and confirm with *Yes*.
. To save the changes, click *OK*.

.Customizing toolbars
. Click menu:Tools[Customize > Toolbars].
. In the right column in the *Target* drop-down box, select the toolbar you want to customize.
. Select the commands you want to appear in the toolbar.
. To switch back to the original settings, click *Defaults* and confirm with *Yes*.
. To save the changes, click *OK*.

.Customizing context menus
You can modify commands, rearrange the items of a context menu, or even create new commands.

[NOTE]
====
The *Context Menus* tab is only available in an open document.
====

. Open a document. In the customization dialog, click the tab *Context Menus*.
. In the left column, select a *Category*. In the right column, select the *Target*.
. To add a separator or submenu, click *Insert*. To rename a command, select the command in the right column and click *Modify*.
. To switch back to the original settings, click *Defaults* and confirm with *Yes*.
. To save the changes, click *OK*.

.Customizing events
{libo} also provides ways to assign macros to events such as application start-up or the saving of a document. The assigned macro runs automatically whenever the selected event occurs.

. Click menu:Tools[Customize > Events].
. Select the event you want to change.
. Assign or remove macros for the selected event by either clicking on *Macro* or *Remove*.
. To save the changes, click *OK*.

.Customizing key combinations
You can reassign key combinations and assign new ones to frequently used functions.

[NOTE]
====
The *Keyboard* tab is only available in an open document.
====

. Open a document and click menu:Tools[Customize > Keyboard].
. In the *Shortcut Keys* box, select the key or key combination you want to assign a command to.
. Select a *Category* and *Function* at the bottom of the dialog.
. Click *Modify* to assign the function to the key or *Delete* to remove an existing assignment.
. To save the changes, click *OK*.

[#sec-lo-oview-templates]
== Using templates

A template is a document containing only the styles—and content—that you want to appear in every document of that type. When a document is created or opened with the template, the styles are automatically applied to that document. Templates enhance the use of {libo} by simplifying formatting tasks for a variety of different documents.

For example, in a word processor, you can write letters, memos and reports, all of which look different and require different styles. Or, for example, for spreadsheets, you could use different cell styles or headings for certain types of spreadsheets. If you use templates for each of your document types, the styles you need for each document are always readily available.

{libo} comes with a set of predefined templates. You can also find additional templates on the Internet, for example at link:https://extensions.libreoffice.org/[]. For details, see <<sec-lo-oview-help,More information>>.

Creating your own templates requires some planning. You need to determine how you want the document to look, so you can create the styles you need in that template.

A detailed explanation of templates is beyond the scope of this section. <<pro-lo-oview-templates,Creating {libo} templates>> only shows how to generate a template from an existing document.

[#pro-lo-oview-templates]
.Creating {libo} templates
For text documents, spreadsheets, presentations and drawings, you can create a template from an existing document as follows:

. Start {libo} and open or create a document that contains the styles and content that you want to re-use for other documents of that type.
. Click menu:File[Templates > Save as Template].
. Choose a *Template Name* and *Category*.
. Confirm with *Save*.

[NOTE]
.Converting Microsoft Word templates
====
You can convert Microsoft Word templates like you would convert any other Word document. For more information, see <<sec-lo-oview-migration-convert,Converting documents to the OpenDocument format>>.
====

[#sec-lo-overview-properties]
== Setting metadata and properties

When exchanging documents with other people, it is sometimes useful to store metadata like the owner of the file, who it was received from, and a URL. {libo} lets you attach such metadata to the file. This helps you track metadata which you do not want to or cannot save in the content of the file. This feature is also the basis for later sorting, searching and retrieving your documents based on metadata.

As an example, we assume you want to set these properties in your file:

* A title, subject and some keywords
* The owner of the file
* Who sent you the file

To attach such metadata to your document, proceed as follows:

.Setting properties
. Click menu:File[Properties].
. Change to the *Description* tab and insert title, subject and your keywords.
. In case you want to add additional data to your document, switch to the *Custom Properties* tab.
. [[st-lo-property-add]]To add a property, click *Add Property*.
. In the *Name* column, click the drop-down box for the entry. A list of properties appears. Choose, for example, *Owner*.
. Select the type (for example, *Text*) and insert the name of the owner in the *Value* column.
. Repeat from <<st-lo-property-add,this step>> for more custom properties.
+
To remove a custom property, click the red icon at the end of the corresponding row.
. To save the changes, click *OK*.
. Save the file.
